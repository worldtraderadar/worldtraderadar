## How to read Llama’s CMO

Llama **final** CMO 8.375 is mostly playbook fallback, not Llama CMO quality. Direct LLM text averages **5.406**, first-shot pass is **6.2%**, and **26/32** cases land on `PLAYBOOK_FALLBACK`. Comparing Qwen 10.469 vs Llama 8.375 understates the real-LLM gap.

Qwen served every case as real LLM (fallback 0). One validator REJECT (3.1%) still recovered to a scored CMO reply.

## DECISION vs the V5.9 log replay

V5.9 Qwen logs replayed on this evaluator reached DECISION mean **1.656** (SCORER_MISS 0/32). This **live** Qwen run is **1.094**. That is generation variance / remaining no-stance replies (14/32), not evaluator noise. The remaining misses are true empty-stance outputs on this sample, not matcher false negatives.

## Safety

Both models: FALSE_CERTAINTY = 0, UNSUPPORTED_FACT = 0. Hard gate holds.

## Recommendation

**Retain Llama3 as the production default. Keep Qwen as the 10% SHA-256 canary.**

Do **not** set `OLLAMA_REASONING_MODEL=qwen3.5:27b`.

Qwen is the better CMO brain on every quality and reliability axis in this run (DECISION +0.75, ACTION +0.375, CMO +2.09, REAL_MISS 14 vs 25, first-shot 97% vs 6%, fallback 0 vs 81%). Safety is equal (0/0). That supports **keeping and trusting the canary**, not a silent 100% default flip.

Reasons not to switch the production default on this scoreboard:

1. **Latency:** Qwen ~12.0 s vs Llama ~4.8 s (~2.5×). A default flip would slow ~90% of sessions.
2. **VRAM:** Dual-resident peak 22424 / 23040 MiB. 100% Qwen plus residual Llama residency is an ops risk on this GPU, not a quality question.
3. **Canary already exists:** `MODEL_CANARY_PERCENT=10` is the controlled way to give Qwen live traffic. Quality win belongs there until latency/VRAM and DECISION miss (14/32) are addressed.
4. **Llama “CMO” is fallback quality.** Replacing default Llama with Qwen would change the typical path from fast playbook to a 12 s real LLM. That is a product rollout, not a scorer-driven cutover.

This run did not change production routing, canary percent, validator REJECT rules, or `CMO_CONTRACT`.
